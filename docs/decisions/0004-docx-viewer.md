# 0004 — Базовые библиотеки для просмотра DOCX

Статус: принято 1 ноября 2026 года для версии 0.2.0.

Пользователь разрешил стандартные библиотеки, средства Windows и отдельно выбранные небольшие зависимости; готовые редакторы и движки документов исключены.

Используются `flate2 = 1.1.5` с `default-features = false`, `rust_backend` только для DEFLATE и `roxmltree = 0.21.2` для разбора XML. ZIP-каталог, проверки контейнера, OOXML, стили, модель и пагинация написаны в Paperik. `windows = 0.62.2` и `windows-numerics = 0.3.1` предоставляют типизированные COM-интерфейсы DirectWrite/Direct2D; `windows-sys` остаётся для Win32. Эти компоненты не являются редактором документов.

Условия закреплённых пакетов взяты из Cargo metadata и upstream-файлов в загруженных пакетах. Для двойных MIT/Apache выбрана MIT; для simd-adler32 — MIT, unicode-ident также сохраняет Unicode-3.0. Все исходные уведомления консервативно включены в `licenses/cargo/`, включая build-time зависимости. Cargo.lock закрепляет транзитивные версии. Библиотеки C/C++, MSVC и готовая конвертация DOCX не добавляются. Сборка остаётся GNU/LLVM.

Проверки: тесты контейнера/стилей, синтетический DOCX, скрытая нативная отрисовка, Clippy, release и автономный запуск. Независимая проверка совпадения с Word остаётся открытой.
