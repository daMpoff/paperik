## Открытые вопросы

- Проверенные минимальные версии Windows. Rust и компоненты первой сборки закреплены в решении 0003 и `rust-toolchain.toml`.
- Зависимости для HTTP и последующих задач; ZIP/XML для просмотра закреплены решением 0004.
- Формат проектов, постоянного дерева версий и индекса; стратегия миграций. Локальные снимки v1, v2 и v3 описаны в [0007](0007-session-recovery.md), [0013](0013-table-structure.md) и [0014](0014-picture-editing.md).
- Допуски для расширенного набора документов и общие критерии визуального сравнения. Независимый эталон первого шаблона получен; его измерения и условия закреплены в [отчёте 0.2.1](../fidelity-0.2.1.md).
- Реализация собственного PDF-экспорта.
- Протокол совместного редактирования, CRDT/OT и необходимость Go-сервера.
