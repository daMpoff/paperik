# 0006 — Сохранение копии DOCX из исходного пакета

Статус: принято для 0.4.0, 1 ноября 2026 года.

Абзацы и runs хранят координаты своего источника. Неизменённый документ копируется побайтно. При правках основной XML меняется по областям: неизменённые абзацы копируются дословно, изменённые получают исходные pPr/rPr и новый текст. Наследуемые шрифты не подменяются приближённым набором свойств. Совпадение разрешённых Font не означает равенство неизвестных XML-свойств; происхождение проверяется отдельно. Namespace bindings сохраняются, текст экранируется, пробелы помечаются xml:space, табуляции и мягкие переносы кодируются отдельными элементами.

Другие части пакета и сжатые payload сохраняются. ZIP-каталог и заголовки собираются собственным кодом; перед записью проверяются CRC, ограничения контейнера и повторное чтение модели. Счётчик Pages может обновляться по текущей вёрстке. proofErr и lastRenderedPageBreak в изменённых абзацах считаются устаревшими кэшами и удаляются; неизменённый XML сохраняет их. Клонирование не повторяет уникальные paraId/textId.

Для закладок, полей, скрытых runs и неизвестной структуры нет доказанного преобразования — соответствующий абзац доступен только для чтения. Цифровые подписи и перенос runs между разными стилями абзаца при экспорте отклоняются. Изменения разделов и колонтитулов не экспортируются. Ошибка сохраняет данные в памяти и не создаёт целевой файл.

Первая команда сохранения всегда создаёт новый файл. Данные полностью записываются и sync_all вызывается до публикации. На Windows используется MoveFileExW без MOVEFILE_REPLACE_EXISTING, со временным файлом в той же папке. Существующий путь не заменяется, даже если появился во время сохранения. Гарантии при отключении питания зависят от ОС, файловой системы и накопителя; автосохранение/восстановление ещё не реализованы.

Новых Cargo-пакетов нет: используются существующие roxmltree, flate2 и windows-sys с Win32_Storage_FileSystem, стандартная библиотека и системный Kernel32. GNU/LLVM-сборка сохраняется; сторонние офисные программы не запускаются.

Проверки описаны в `../testing.md`. Сохранённые файлы проверены собственным читателем и рендером; независимое открытие в Word остаётся отдельной проверкой.

Первичные источники: [WordprocessingML](https://learn.microsoft.com/en-us/office/open-xml/word/structure-of-a-wordprocessingml-document), [свойства runs](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.runproperties), [MoveFileExW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw).
