# 0012 — Редактирование текста в ячейках и между объектами

Статус: принято для локальной реализации без коммита и публикации. Заменяет запрет текстовых правок из [0011](0011-read-only-blocks.md); ограничения отображаемого подмножества сохраняются.

Проблема: общий массив абзацев сам по себе не сохраняет принадлежность ячейке. Обычный splice может удалить границу объекта, а новые абзацы сдвигают индексы рисунков и следующих ячеек. Поэтому простое снятие read-only небезопасно.

Решение: выделить независимые текстовые области. Одна ячейка — одна область, последовательные обычные абзацы между объектами — другая, рисунок — защищённая область. Правка проверяется до изменения; запрещён выход за границу и использование оформления из другой ячейки. Минимум один абзац на область сохраняется.

После splice модель блоков перепривязывается по исходным координатам абзацев. Это поддерживает Enter и объединение внутри ячейки без изменения таблицы. Undo/Redo сохраняют полную структуру, восстановление заново выводит её из исходника и сохранённых привязок. Проверяются порядок областей, защищённые абзацы и источники runs. Новая версия формата recovery не нужна.

Экспорт заменяет группы абзацев на месте в исходном XML. Сетки, свойства таблиц/ячеек, drawing и байты медиа не пересобираются. Незатронутые абзацы используются как исходный XML. Сохранение заново импортирует результат и сравнивает текст, форматирование и модель блоков; исходный файл не перезаписывается.

Для таблиц ввод по координате сначала выбирает ячейку, затем строку. Вертикальная навигация учитывает её геометрию. Повторяемая шапка имеет общую логическую позицию, но курсор выбирает визуальную страницу с учётом последнего щелчка/перехода. Данные подсказки страницы относятся к UI, а не к содержимому документа.

Ограничения: текстовая правка не меняет сетку, строки/колонки или сами изображения. Высота строки растёт, целая строка может перейти на следующую страницу; разбиение внутри строки пока не реализовано. Непомещающаяся правка откатывается до фиксации модели. Все проверки и пределы — [complex-documents.md](../complex-documents.md) и [testing.md](../testing.md). Новых библиотек и готовых редакторов не подключено.
