# Ресурсы бренда

Логотип, знак и леттеринг предоставлены пользователем для Paperik. Использовать исходные SVG с сохранением пропорций. Варианты `reverse` предназначены для тёмного фона, `mono` — для одноцветного воспроизведения. `paperik-app.ico` — иконка Windows.

`paperik-tokens.json` — источник значений для оформления интерфейса. Шрифты в комплект не включены. Шрифт документа, размеры, интервалы и поля не заменяются токенами интерфейса.

Брендбук и референс интерфейса находятся в [docs/brand](../../docs/brand/README.md). Публичная лицензия собственным ресурсам автоматически не назначается.
