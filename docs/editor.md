# Редактирование текста 0.4.0

Предварительный редактор работает поверх собственной модели и вёрстки. **«Сохранить копию» / Ctrl+S записывает отредактированный документ в новый DOCX. Существующие файлы не перезаписываются.** При закрытии или открытии другого файла можно сохранить копию, продолжить без сохранения или отменить действие. Автосохранения и восстановления после сбоя пока нет.

## Управление

- Щелчок по странице — курсор; перетаскивание — выделение, включая соседние страницы. При выходе за верх/низ области документ прокручивается. Двойной щелчок — слово; Shift+щелчок — расширение выделения.
- Стрелки — перемещение; Ctrl+влево/вправо — по словам. Shift расширяет выделение. Home/End — край строки, Ctrl+Home/End — начало/конец документа. Page Up/Down — перемещение на несколько строк с прокруткой.
- Enter — новый абзац с текущим оформлением; Shift+Enter — мягкий перенос; Tab — табуляция. Backspace/Delete удаляют выделение или целую графему, Ctrl — до границы слова.
- Ctrl+A — выделить всё; Ctrl+C/X/V — обычный текст Unicode. Форматирование из буфера пока не импортируется; вставка наследует шрифт позиции, остальные фрагменты сохраняют свои свойства. Вырезание применяется после успешного копирования.
- Ctrl+Z — отменить; Ctrl+Y или Ctrl+Shift+Z — повторить. Каждая операция создаёт снимок; новая правка после отмены удаляет ветку повтора.
- Ctrl+S или Ctrl+Shift+S — сохранить новую копию; Ctrl+O — открыть; Ctrl+колесо, Ctrl+плюс/минус — масштаб; Ctrl+0 — по ширине. Масштаб и тема не меняют оформление документа.

## Сохранность и ограничения

Позиции измеряются в UTF-16 для DirectWrite и приводятся к границам расширенных графем: составные буквы, пары surrogate, флаги и эмодзи с ZWJ не разрываются. Новые абзацы копируют стиль и базовые сведения списка; явный разрыв страницы не дублируется. Простая десятичная нумерация пересчитывается. Сложные многоуровневые списки и продолжение их счётчиков не считаются полностью поддержанными.

Изменение сначала готовится на копии модели, затем проходит вёрстку. Только успешный результат заменяет модель и геометрию вместе. Устаревшая подготовленная команда отклоняется. Undo/Redo восстанавливают модель, оформление и положение выделения. Исходный ZIP остаётся общим неизменяемым блоком. Сохранение не очищает Undo/Redo: фиксируется сохранённая ревизия, отмена к другой ревизии снова показывает несохранённые правки.

История — до 256 снимков и примерно 32 МиБ собственных данных модели по оценке; старые снимки вытесняются. Это временная линейная история сессии, а не будущее дерево версий. Нет автосохранения и восстановления после сбоя. Ограничение редактирования — 16 МиБ текста, 10 000 абзацев и 200 000 байт UTF-8 в абзаце. Неподдерживаемые управляющие символы отклоняются.

Редактируется основной текст; нижние колонтитулы и поля не редактируются. Таблицы, изображения, формулы и остальные ограничения [чтения DOCX](docx-viewer.md) сохраняются. Инкрементальная вёрстка, форматирование через панель, поиск и доступность через UI Automation ещё впереди. При большом масштабе горизонтальная прокрутка пока отсутствует — используйте Ctrl+0.

IME передаёт готовую строку одной операцией, а предварительную композицию и кандидаты отображляет Windows. Полученный результат не отправляется повторно в стандартный обработчик. Реальный прогон с IME ещё нужен: [границы проверки](testing.md). ИИ не подключён и текст никуда не отправляется.

## Как сохраняется оформление

Неизменённая копия совпадает с исходником побайтно. При правках незатронутые абзацы сохраняют исходный XML; изменённые собираются из исходных pPr/rPr и нового текста. Сведения о происхождении runs не позволяют спутать одинаковые разрешённые шрифты с разными XML-свойствами. Стили, numbering, relationships, колонтитулы и непрозрачные части пакета остаются прежними. Изменяется основная часть документа и, при наличии счётчика, метаданные Pages. Устаревшие proofErr и lastRenderedPageBreak удаляются только из пересобранных абзацев. При клонировании абзаца не дублируются paraId/textId; явный разрыв страницы не переносится на новый абзац.

Перед записью результат повторно читается и сравнивается с текущими текстом, свойствами шрифтов, абзацев, списков и страницы. ZIP собирается собственным кодом; формат XML целиком не сериализуется заново. Файл сначала полностью записывается во временный соседний файл, синхронизируется и переименовывается без замены существующего пути. Ошибка не сбрасывает признак несохранённых изменений.

Абзацы с закладками, ссылками, полями, скрытыми фрагментами и неподдерживаемыми элементами доступны только для чтения. Нет сохранения изменений цифровой подписи, изменения разделов/колонтитулов и объединения текста из разных стилей абзаца. Последнее может редактироваться в памяти, но сохранение будет явно отклонено: правки останутся доступными для отмены. Полная совместимость с Word не заявляется; независимое открытие сохранённого результата в Word ещё требует проверки.

После каждого Ctrl+S выбирается **новое имя**. Обычное обновление уже сохранённого файла, постоянная история и аварийное восстановление — следующие задачи.
