Paperik 0.5.0 — редактирование и сохранение копии DOCX, Windows x64

Распакуйте архив целиком и запустите paperik.exe. Ctrl+O — открыть DOCX.
Кнопка «Сохранить копию» или Ctrl+S — сохранить в новый файл.
После каждого сохранения выбирается новое имя: существующие файлы,
включая исходник, не перезаписываются. При закрытии можно сохранить
копию, отказаться от сохранения или отменить закрытие.

Щелчок — курсор, перетаскивание — выделение, двойной щелчок — слово.
Shift+стрелки — выделение, Ctrl+стрелки — по словам, Ctrl+A — всё.
Enter — абзац; Shift+Enter — мягкий перенос; Tab — табуляция.
Backspace/Delete — удалить; Ctrl+C/X/V — обычный текст буфера обмена.
Ctrl+Z — отменить; Ctrl+Y или Ctrl+Shift+Z — повторить.
Home/End — край строки; Ctrl+Home/End — начало/конец документа.
Колесо — прокрутка; Ctrl+колесо — масштаб; Ctrl+0 — по ширине.

При росте текста добавляются страницы, оформление не уменьшается.
Перед записью проверяются текст и свойства повторным чтением DOCX.
Поддержаны текст, базовые списки, один раздел и нижний колонтитул.
Служебные объекты в абзаце могут ограничить его редактирование.
Объединение текста из разных стилей абзаца не сохраняется.
Колонтитулы не редактируются. Сложные объекты DOCX отклоняются.
Полная совместимость с Word не заявляется; независимое открытие
нового экспорта в Word и полный ручной прогон ещё требуют проверки.

Автосохранение включено: локальный черновик примерно раз в 5 секунд.
После сбоя можно восстановить текст, оформление, курсор и Undo/Redo.
Кнопка «Восстановить сессию» слева открывает выбор повторно.
Данные: %LOCALAPPDATA%\Paperik\Recovery. Исходник не перезаписывается.
Хранятся два поколения, при повреждении последнего выбирается предыдущее.
Черновики содержат данные документа и не шифруются. В поставку не входят.
Последние изменения после исправного снимка могут быть потеряны.
История ограничена; обычные копии DOCX сохраняйте вручную.
ИИ пока не подключён.
Rust, Cargo, Microsoft Build Tools и Ollama для запуска не требуются.
Шрифты и системные DLL не поставляются. Чистая Windows VM не проверена.
