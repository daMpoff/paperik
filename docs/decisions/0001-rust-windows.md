# 0001 Rust и собственный интерфейс Windows

Дата: 1 ноября 2026 года. Статус: принято пользователем в обсуждении проекта; конкретные версии и зависимости ещё не выбраны.

## Контекст

Нужно самостоятельное приложение с собственным редактором и приоритетом точной вёрстки. Пользователь разрешил стандартные библиотеки и системные средства Windows, а дополнительные небольшие зависимости — выбирать отдельно. Использование двух языков с первой версии не даёт автоматического ускорения и усложняет сборку и отладку.

## Решение

Первая версия реализуется на Rust. Окна и ввод — Win32, графика — Direct2D, шрифты — DirectWrite, с подходящими Rust-привязками к Windows API. Интерфейс, логика редактора и страницы разрабатываются в проекте. Готовые редакторы и движки документов не подключаются.

Go отложен до конкретной задачи сервера совместной работы. В первой версии не создаётся отдельный Go-сервис только ради HTTP-запросов к Ollama. Portable-поставка и установщик должны работать без установленного Rust или Go. Ollama поставляется отдельно.

## Последствия

Получаем контроль над вводом, памятью, вёрсткой и отрисовкой. Самостоятельная реализация UI требует работы над доступностью, составным вводом, масштабированием и стандартным поведением элементов. Интерфейс первой версии привязан к Windows; перенос потребует другого платформенного адаптера.

Отсутствие сборщика мусора не гарантирует скорость конкретного кода. Выигрыш оптимизаций доказывается измерениями. Системные средства рисования текста не гарантируют совпадение с Word.
