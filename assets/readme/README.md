# Изображения README

`hero.svg` — обложка в палитре Paperik. Знак и леттеринг взяты из `../brand/` с сохранением пропорций; шрифты не встраиваются.

`interface-light.png` и `interface-dark.png` — рендер элемента `.app` из `../../docs/brand/interface.html`, ширина окна 1440 px, масштаб 1×. Это концепция с вымышленными данными, не снимки текущей сборки. Источник макета хранится отдельно от PNG.

Ресурсы используются в корневом README. Исходные пользовательские документы и изображения страниц в этот каталог не добавляются.
