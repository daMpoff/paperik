# Paperik 0.4.0 — сохранение копии DOCX

Предварительная версия для Windows x64. Добавлена кнопка «Сохранить копию» и Ctrl+S: отредактированный документ записывается в новый DOCX с оформлением шаблона. Существующие файлы не перезаписываются. После каждого сохранения нужно новое имя.

## Что добавлено

- Сохранение из исходного пакета с исходными свойствами абзацев и runs; незатронутые части остаются прежними.
- Повторное чтение и проверка текста/оформления перед записью; запись через временный файл и отказ от замены существующего пути.
- Предложение сохранить копию при закрытии или открытии другого документа.
- Отслеживание сохранённой ревизии без очистки Undo/Redo.
- Защита служебных объектов и неизвестной структуры от неподдерживаемого редактирования.

## Проверки

46 тестов, форматирование, Clippy, GNU/LLVM-сборка и автономный запуск с PATH только System32. Личный шаблон сохранил 9 страниц; копия без изменений побайтно равна исходнику. Добавление 80 абзацев сохранилось в 12 страниц, первые 8 страниц собственного рендера остались прежними. Личные документы и изображения в выпуск не включены.

## Ограничения

Нет автосохранения, восстановления после сбоя, ИИ и полной совместимости с Word. Служебные объекты могут делать абзац доступным только для чтения. Объединение текста из разных стилей абзаца, изменение разделов/колонтитулов и документов с цифровой подписью не экспортируются. Полный ручной прогон, IME, независимое открытие экспорта в Word и чистая Windows VM ещё требуют проверки.

Скачайте ZIP, распакуйте целиком и запустите `paperik.exe`. В комплекте exe, инструкция и лицензионные уведомления; рядом приложен SHA-256. Rust и Ollama для запуска не нужны.
