# Paperik 0.3.0 — курсор и редактирование текста

Предварительный выпуск для Windows x64. Собственные модель документа, вёрстка и интерфейс на Rust; без Word и других офисных движков.

**Правки хранятся только в памяти. Сохранение DOCX, автосохранение и восстановление после перезапуска ещё не реализованы.** Исходный файл не перезаписывается. При закрытии с правками появляется предупреждение. ИИ пока не подключён.

## Добавлено

- Курсор, выделение мышью, двойной щелчок по слову и выделение с Shift.
- Ввод и замена текста, Enter/Shift+Enter, Tab, Backspace/Delete, перемещение по словам и строкам.
- Копирование, вырезание и вставка обычного Unicode-текста.
- Undo/Redo с восстановлением оформления и выделения.
- Пересчёт страниц при росте текста, наследование оформления и продолжение простой нумерации.
- Границы графем Unicode и адаптер Windows IME.

## Проверки и ограничения

Прошли форматирование, Clippy, 34 автоматических теста и GNU/LLVM-сборка. Автономный запуск проверен с PATH только System32. Первый шаблон сохранил 9 страниц, 237 непустых строк и прежние допуски точности.

Полный ручной прогон, clipboard round-trip с другими приложениями, реальная IME и чистая Windows VM ещё требуют проверки. Захват окна через Computer Use не дал проверяемого изображения. Поддерживается ограниченное подмножество DOCX: текст, базовые списки, один раздел и нижний колонтитул; сложные объекты отклоняются. История сессии ограничена, постоянное дерево версий не реализовано.

## Запуск

Скачайте `paperik-0.3.0-windows-x64.zip`, распакуйте целиком и запустите `paperik.exe`. Rust и Ollama для запуска не нужны. Рядом приложен SHA-256 архива. Архив включает exe, инструкцию и лицензионные уведомления; личных документов, системных DLL, шрифтов и моделей в нём нет.
