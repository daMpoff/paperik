Paperik 0.3.0 — предварительный редактор DOCX для Windows x64

Распакуйте архив целиком и запустите paperik.exe. Можно перетащить DOCX
в окно или открыть его через Ctrl+O.

ВАЖНО: правки хранятся только в памяти. Сохранение DOCX и восстановление
после перезапуска пока не реализованы. Исходный файл не перезаписывается.
При закрытии с правками появляется предупреждение. ИИ пока не подключён.

Щелчок — курсор, перетаскивание — выделение, двойной щелчок — слово.
Shift+стрелки — выделение, Ctrl+стрелки — по словам, Ctrl+A — всё.
Enter — абзац, Shift+Enter — мягкий перенос, Tab — табуляция.
Backspace/Delete — удалить; Ctrl+C/X/V — обычный текст буфера обмена.
Ctrl+Z — отменить; Ctrl+Y или Ctrl+Shift+Z — повторить.
Home/End — край строки; Ctrl+Home/End — начало/конец документа.
Колесо — прокрутка; Ctrl+колесо — масштаб; Ctrl+0 — по ширине.

Оформление соседнего текста сохраняется, страницы пересчитываются.
История временная: до 256 снимков и около 32 МиБ данных модели.
Поддержаны текст, базовые списки, один раздел и нижний колонтитул.
Колонтитул не редактируется. Сложные объекты DOCX отклоняются.
Первый шаблон проверен по PDF Word: 9 страниц, переносы строк совпали.
Это не гарантия точности любого DOCX или идентичного сглаживания.

Rust, Cargo, Microsoft Build Tools и Ollama для запуска не требуются.
Шрифты и системные DLL не поставляются. Проверено на машине разработки;
чистая Windows VM, полный ручной прогон и реальная IME ещё требуют проверки.

Диагностика: --version, --inspect файл.docx, --smoke-test [файл.docx].
--render-pages файл.docx новая-папка создаёт PNG 144 dpi и координаты TSV;
--layout-report файл.docx выводит геометрию без содержимого текста.
