# Сравнение DOCX с PDF-эталоном

Необязательная локальная QA-утилита, не часть приложения. Зависимость: `pdfplumber==0.11.9` (MIT, https://github.com/jsvine/pdfplumber), уже установленная в среде проверки. При необходимости: `python -m pip install pdfplumber==0.11.9`. Библиотека и её зависимости не копируются в репозиторий или exe.

Применение и допуски — в `../../docs/fidelity-0.2.1.md`. Утилита рассчитана на текстовые страницы Word, один раздел, обычный горизонтальный текст и автоматические списки с маркером en dash. Она исключает такие маркеры в начале PDF-строки из сопоставления; ручные начальные тире, формулы, надстрочные знаки и сложный порядок чтения требуют расширения проверки. PNG просматриваются отдельно. В отчёт не записываются текст и локальные пути. Личные входные файлы и изображения не коммитить.
