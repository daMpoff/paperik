# 0011 — Собственный просмотр таблиц и встроенных растров

Статус: принято для локальной реализации, без публикации.

Проблема: DOCX с таблицей или drawing целиком отклонялся импортом, а причина могла остаться незаметной в строке состояния при уже открытом документе. Отказ по-прежнему нужен для неподдерживаемых конструкций, но базовые таблицы и растры можно показать собственным движком.

Решение: добавить упорядоченные блоки и геометрию таблиц, оставить общий массив абзацев для текста и выделения. Сложные документы открывать целиком только для чтения; не допускать рассогласования таблиц, текста и экспорта. Неизменённая копия возвращает исходный пакет. Текстовый путь вёрстки остаётся отдельным и проверяется регрессией первого шаблона.

PNG/JPEG декодируются уже разрешённым системным WIC вне UI, с ограничениями до выделения пиксельного буфера. Между worker и UI передаются пиксели и геометрия, не WIC/COM-объекты. Окно и диагностический PNG используют один путь рисования. Готовые редакторы, конвертеры, SDK документов и новые crates не используются.

При отказе открытия видимое окно показывает отдельный диалог; предыдущий документ остаётся в памяти. Диалог создаётся после извлечения принадлежащей ему строки из State, без удержания Rust-заимствования на время MessageBox. Отключённый владелец не обрабатывает фоновые результаты.

Пределы и незавершённая совместимость явно описаны в [complex-documents.md](../complex-documents.md). Поддержка не означает полное воспроизведение Word и не закрывает PPK-017.

Схема сверялась с [описанием WordprocessingML-таблиц Microsoft](https://learn.microsoft.com/en-us/office/open-xml/word/working-with-wordprocessingml-tables); декодирование — с [API WIC](https://learn.microsoft.com/en-us/windows/win32/api/wincodec/nf-wincodec-iwicimagingfactory-createdecoderfromstream). Реализация собственная, приведённый там код не переносился.

Часть о запрете всего редактирования заменена [решением 0012](0012-block-text-editing.md): теперь разрешены текстовые правки внутри независимых областей с сохранением объектов.
