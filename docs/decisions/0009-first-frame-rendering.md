# 0009 — Программный рендер окна без ожидания обновления экрана

Статус: принято 2 ноября 2026 года для main после 0.5.0.

## Контекст

В пробнике фоновых операций одна итерация resize/paint/poll заняла 311 мс. Для разделения причин добавлен отдельный release-пробник: создание окна, создание Direct2D-поверхности, подготовка рисунка и EndDraw измеряются отдельно, включая первый вызов. В текущих парных измерениях главное различие оказалось в создании поверхности DEFAULT, а ожидание обновления экрана увеличивало время следующих кадров.

## Решение

Окно создаёт Direct2D-поверхность с SOFTWARE и IMMEDIATELY. Текущий интерфейс рисует текст и простые фигуры по запросу, поэтому этот выбор позволяет сократить старт без изменения формата документов, вёрстки, DPI и шрифтов. Инициализация остаётся внутри полного замера первого кадра: скрытый прогрев и перенос ожидания перед таймером не используются.

Тестовый конструктор позволяет сравнивать прежний DEFAULT/NONE с текущим Renderer::new в одном и том же release-пробнике, но в отдельных процессах. Порядок режимов чередуется. QA-параметры режима/DPI читает только игнорируемый тест; обычный exe не меняет поведение от этих переменных окружения.

## Последствия

Растеризация окна выполняется на CPU. Это выбор для нынешних текстовых страниц, а не обещание превосходства программного рендера для изображений, анимации или любых устройств. При расширении графики нужно повторно оценить задержки, CPU и память. Оконный compositor и системные вызовы Windows по-прежнему влияют на фактическое появление изображения.

Измерены новые процессы при 96/192 DPI, отдельно проверен кадр синтетического документа, повторён пробник ввода/сохранения и рендер приватного шаблона. [Методика и результаты](../testing.md), [скрипт](../../scripts/measure-first-frame.ps1). Зависимости и GNU/LLVM-сборка не изменены.

Платформенные основания: [тип поверхности Direct2D](https://learn.microsoft.com/en-us/windows/win32/api/d2d1/ne-d2d1-d2d1_render_target_type), [режим показа](https://learn.microsoft.com/en-us/windows/win32/api/d2d1/ne-d2d1-d2d1_present_options).
