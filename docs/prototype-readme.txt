Paperik 0.2.0 — просмотр DOCX для Windows x64

Распакуйте архив целиком и запустите paperik.exe.
Ctrl+O — открыть DOCX, колесо — прокрутка, Ctrl+колесо — масштаб,
Ctrl+0 — по ширине, Home/End — начало/конец. Можно перетащить файл в окно.

Собственные чтение DOCX, разрешение стилей и вёрстка страниц.
Исходник не изменяется. Редактирования, сохранения и ИИ пока нет.
Поддерживается ограниченное подмножество DOCX: текст, базовые списки,
один раздел и нижний колонтитул. Сложные объекты отклоняются.
Совпадение с Word не подтверждено; число страниц может отличаться.
Отсутствующие шрифты и расхождение с метаданными показаны в интерфейсе.

Rust, Cargo, Microsoft Build Tools и Ollama для запуска не требуются.
Шрифты и системные DLL не поставляются. Проверено на компьютере
разработки; проверка чистой Windows VM ещё не выполнена.

Диагностика: --version, --inspect файл.docx, --smoke-test [файл.docx].
Уведомления: THIRD_PARTY_NOTICES.md и каталог licenses/.
Проект и ограничения: https://github.com/daMpoff/paperik
